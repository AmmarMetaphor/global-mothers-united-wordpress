Global Mothers United WordPress Theme
=====================================

This theme was converted from the supplied static HTML files.

Install:
1. WordPress Dashboard > Appearance > Themes > Add Theme > Upload Theme.
2. Upload gmu-wordpress-theme.zip.
3. Install and Activate.
4. The theme creates Home, Programs, Events, Get Involved, Media and Contact pages automatically.
5. Go to Settings > General and confirm the Administration Email Address. Website form submissions are sent there.
6. Go to Settings > Permalinks and click Save Changes once.
7. Test the Contact and Get Involved forms. If email delivery is unreliable, configure SMTP with a reputable SMTP plugin/service.

Important:
- The supplied design displays info@globalmothersunited.org. Verify that address before launch.
- The source design loads some imagery from Unsplash and fonts from Google Fonts.
- Page design/content is coded in theme template files rather than the WordPress block editor.
