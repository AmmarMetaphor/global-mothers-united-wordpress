Global Mothers United WordPress Theme
=====================================

PREVIEW BUILD
-------------
This is a preview build. Install it as an inactive WordPress theme.
Use Live Preview before activation. Keep the existing production Global
Mothers United theme installed and active on the live site for rollback
until this preview has been reviewed and approved.

Note on Live Preview: the automatic page creation described in step 4
below (Home, Programs, Events, Get Involved, Media, Contact) runs on
theme activation, not on Live Preview alone. If those pages do not
already exist on the site being previewed, some navigation links may not
resolve until the theme is actually activated.

This theme was converted from the supplied static HTML files.

Install:
1. WordPress Dashboard > Appearance > Themes > Add Theme > Upload Theme.
2. Upload the theme zip.
3. Click Install. Do not activate yet — use Live Preview first (see
   "Preview Build" above). Only activate once the preview has been
   reviewed and approved.
4. On activation, the theme creates Home, Programs, Events, Get Involved, Media and Contact pages automatically.
5. Go to Settings > General and confirm the Administration Email Address. Website form submissions are sent there.
6. Go to Settings > Permalinks and click Save Changes once.
7. Test the Contact and Get Involved forms. If email delivery is unreliable, configure SMTP with a reputable SMTP plugin/service.

Important:
- The supplied design displays info@globalmothersunited.org. Verify that address before launch.
- The source design loads some imagery from Unsplash and fonts from Google Fonts.
- Page design/content is coded in theme template files rather than the WordPress block editor.
